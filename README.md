# School Events Hub

A place to keep track of every school event — announcements, an interactive
calendar, online registrations, and online tickets.

Built with Astro, React islands, and Tailwind. Data lives in a Supabase
Postgres database.

## Development

```sh
npm install
npm run dev
```

```sh
npm run build   # production build → dist/
```

## Stack

- Astro (static output) + React islands
- Tailwind CSS
- Supabase (Postgres, Auth, Row-Level Security, Realtime)
- Hosted on Cloudflare Pages
